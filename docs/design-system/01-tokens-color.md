# Color Tokens

## 라이트 모드 — 시맨틱 토큰

| 토큰                          | 값                    | 역할                       |
| ----------------------------- | --------------------- | -------------------------- |
| `--background`                | `#FBF9F9`             | 페이지 배경                |
| `--surface`                   | `#FBF9F9`             | 기본 서피스                |
| `--surface-dim`               | `#DBDAD9`             | 비활성 서피스              |
| `--surface-container-lowest`  | `#FFFFFF`             | 최하위 컨테이너            |
| `--surface-container-low`     | `#F5F3F3`             | 카드 배경                  |
| `--surface-container`         | `#EFEDED`             | 카드 내부 섹션             |
| `--surface-container-high`    | `#E9E8E7`             | 강조 영역                  |
| `--surface-container-highest` | `#E3E2E2`             | 코드블록·비활성            |
| `--surface-hover`             | `#F3F2F2`             | 호버 배경                  |
| `--surface-active`            | `#ECEBEB`             | 활성 배경                  |
| `--surface-elevated`          | `#FFFFFF`             | 모달·드롭다운              |
| `--surface-overlay`           | `rgba(17,17,17,0.48)` | 모달 딤                    |
| `--on-surface`                | `#1B1C1C`             | 기본 텍스트                |
| `--on-surface-variant`        | `#464555`             | 보조 텍스트                |
| `--outline`                   | `#777587`             | 강조 보더                  |
| `--outline-variant`           | `#C7C4D8`             | Ghost Border               |
| `--primary`                   | `#3525CD`             | CTA                        |
| `--on-primary`                | `#FFFFFF`             | Primary 위 텍스트          |
| `--primary-container`         | `#4F46E5`             | Primary 컨테이너           |
| `--on-primary-container`      | `#DAD7FF`             | Primary 컨테이너 위 텍스트 |
| `--secondary`                 | `#0051D5`             | 정보성 액션                |
| `--on-secondary`              | `#FFFFFF`             | Secondary 위 텍스트        |
| `--error`                     | `#BA1A1A`             | 오류                       |
| `--on-error`                  | `#FFFFFF`             | Error 위 텍스트            |
| `--error-container`           | `#FFDAD6`             | 오류 배경                  |
