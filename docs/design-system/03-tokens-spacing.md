# Spacing & Layout Tokens

## Gap 스케일

| 토큰      | 값              | 사용처                   |
| --------- | --------------- | ------------------------ |
| `gap-xs`  | `0.5rem` (8px)  | 아이콘–텍스트, 뱃지 내부 |
| `gap-sm`  | `1rem` (16px)   | 인라인 요소, 소규모 그룹 |
| `gap-md`  | `1.5rem` (24px) | 카드 내부 패딩, 폼 필드  |
| `gap-lg`  | `2rem` (32px)   | 섹션 내 주요 요소        |
| `gap-xl`  | `3rem` (48px)   | 섹션 간                  |
| `gap-xxl` | `4rem` (64px)   | 대형 섹션, 히어로 여백   |

## 레이아웃 너비

| 토큰             | 값               | 사용처           |
| ---------------- | ---------------- | ---------------- |
| `page-max-width` | `80rem` (1280px) | 전체 페이지      |
| `hero-max-width` | `64rem` (1024px) | 히어로 섹션      |
| `text-max-width` | `48rem` (768px)  | 본문 텍스트 영역 |

## 모바일 기준값

| 영역      | 모바일          | 데스크탑        |
| --------- | --------------- | --------------- |
| 수평 패딩 | `px-4` (16px)   | `px-6` (24px)   |
| 수직 여백 | `py-10` (40px)  | `py-16` (64px)  |
| 카드 패딩 | `p-4` (16px)    | `p-6` (24px)    |
| 요소 gap  | `gap-md` (24px) | `gap-lg` (32px) |
