# Typography Tokens

## 폰트 패밀리

| 역할 | 값                                                       |
| ---- | -------------------------------------------------------- |
| 본문 | `Pretendard Variable, Pretendard, system-ui, sans-serif` |
| 코드 | `JetBrains Mono`                                         |

## 타입 스케일

| 토큰                  | 크기 | 굵기 | 행간 | 자간     | 사용처            |
| --------------------- | ---- | ---- | ---- | -------- | ----------------- |
| `text-title-1`        | 60px | 700  | 1.2  | -0.04em  | 히어로 (데스크탑) |
| `text-title-1-mobile` | 40px | 700  | 1.2  | -0.04em  | 히어로 (모바일)   |
| `text-title-2`        | 36px | 700  | 1.2  | -0.03em  | 섹션 타이틀       |
| `text-title-3`        | 28px | 700  | 1.3  | -0.02em  | 서브 섹션         |
| `text-title-4`        | 20px | 700  | 1.4  | -0.01em  | 카드 제목         |
| `text-body-1`         | 20px | 400  | 1.7  | -0.01em  | 리드 문단         |
| `text-body-2`         | 16px | 400  | 1.7  | -0.01em  | 기본 본문         |
| `text-body-3`         | 14px | 400  | 1.6  | -0.005em | 보조 설명         |
| `text-caption`        | 12px | 400  | 1.5  | 0        | 캡션·메타         |
| `text-button`         | 16px | 600  | 1    | -0.01em  | 버튼 레이블       |
| `code-display`        | 14px | 400  | 1.6  | —        | 코드 블록         |

## 허용 크기 목록

`60 / 40 / 36 / 28 / 20 / 16 / 14 / 12 px`

이 외 크기(`text-[15px]`, `text-[17px]` 등)는 사용하지 않는다.
